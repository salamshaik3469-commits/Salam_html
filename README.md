# TaskFlow — JavaScript Logic & State Management

A complete client-side To-Do List application built with semantic HTML, responsive CSS and vanilla JavaScript.

## Requirements covered

- **Full CRUD:** create, read, update and delete tasks.
- **Persistent data:** tasks are automatically saved with `window.localStorage`.
- **Advanced filtering:** All, Active and Completed views.
- **Dynamic DOM:** task elements are rendered dynamically from application state.
- **Event delegation:** one delegated listener handles controls for dynamically-created tasks.
- **State management:** a single task state is re-rendered after every mutation.
- **Extra functionality:** completion toggle, clear-completed, inline editing, statistics and keyboard shortcuts.
- **Responsive UI:** works across desktop, tablet and mobile screens.
- **Accessibility:** labels, ARIA states, live status messages and reduced-motion support.

## Files

```text
index.html   # Application structure
style.css    # Responsive UI and component styling
script.js    # CRUD, filtering, state and localStorage logic
README.md    # Project documentation
```

## Run locally

Open `index.html` in a modern browser. No framework, package installation or backend is required.
