# Advanced CSS3 & Responsive Architecture — Portfolio

A complete semantic portfolio implementation for the **Advanced CSS3 & Responsive Architecture** assignment.

## Requirements covered

- **CSS Grid:** two-dimensional layouts for hero, content and project sections.
- **Flexbox:** navigation, buttons, tags, statistics and contact controls.
- **Mobile-first responsive design:** fluid typography, responsive grids and mobile/tablet/desktop breakpoints.
- **CSS variables:** centralized design tokens for colors, surfaces, borders, shadows and theme behavior.
- **Light/Dark mode:** persistent theme toggle using CSS custom properties and `localStorage`.
- **Semantic HTML:** header, nav, main, sections, articles and footer.
- **Accessibility:** skip link, accessible controls, labels and reduced-motion support.
- **Modern UI:** responsive cards, glass-style code panel, hover states and subtle reveal animation.

## Files

```text
index.html   # Semantic portfolio structure
style.css    # Advanced CSS3 architecture and responsive layout
script.js    # Theme, navigation and reveal interactions
README.md    # Documentation
```

## Run locally

Open `index.html` in a browser. No framework, build step or package installation is required.

## GitHub Pages

Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will publish the site from `index.html`.

## Assignment mapping

The project intentionally demonstrates CSS Grid for complex two-dimensional structure, Flexbox for component alignment, mobile-first media queries for responsive behavior, and CSS custom properties for a dynamic light/dark theme. It is ready to be reviewed as a complete static portfolio project.
